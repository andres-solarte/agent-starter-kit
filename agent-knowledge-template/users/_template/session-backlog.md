# Session backlog

Personal parked ideas, bugs, or requests (`/ask-backlog` + rules `ask-focus-scope`, `ask-one-item-per-conversation`).

Path: `users/<email>/session-backlog.md` (tracked — can commit with agent-knowledge).

One item per conversation. Resume in a new conversation with `/ask-backlog resume BL-NNN`.

Item format (`Depends on` / `Ticket` / `Resume` optional until known):

```markdown
### BL-001 — short summary
- Status: open | in_progress | blocked | done | discarded
- Added: YYYY-MM-DD · Updated: YYYY-MM-DD
- Depends on: BL-000, REQ-000 (or —)
- Related: BL-000 (or —)
- Ticket: REQ-000 | external key/URL | candidate | —
- Resume: where it stopped; next concrete step; paths / branch / PR
```
