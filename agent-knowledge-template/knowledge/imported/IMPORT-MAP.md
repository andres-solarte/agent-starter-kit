# Documentation import map

Tracks docs **copied** from the multi-repo workspace into `knowledge/` during `/ask-centralize-docs` (or the install scan step).

| Date | Source (workspace path) | Destination (under knowledge/) | Status |
|------|-------------------------|--------------------------------|--------|
| YYYY-MM-DD | `…` | `…` | copied \| stubbed \| original_removed |

Status meanings:

- `copied` — present in agent-knowledge; original may still exist
- `stubbed` — original replaced with a pointer stub
- `original_removed` — original deleted after user confirmation

Do not list secrets or `.env` files.
