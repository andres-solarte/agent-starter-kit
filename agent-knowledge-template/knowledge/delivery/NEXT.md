# NEXT — what to resume

| Field | Value |
|-------|-------|
| Active requirement | (none) — e.g. `REQ-001` |
| Status | — |
| Last closed | — |
| Paused | — |
| Next step | Define the first requirement with `/ask-requirement` |
| Resume line | — e.g. `/ask-requirement resume REQ-001` (paste in a **new conversation**) |
