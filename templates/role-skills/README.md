# role-skills/

Canonical stubs for product **role agents**. Not merged wholesale into a product’s `.cursor/` on install.

`/ask-setup-agents` copies **approved** roles into the product `.cursor/skills/` and fills frontiers from the workspace scan.

| Template | Typical when |
|----------|----------------|
| `ask-role-tech-lead` | Always (unless declined) |
| `ask-role-frontend` | UI apps (Next/React/…) |
| `ask-role-backend` | API services |
| `ask-role-data` | Migrations / ORM / SQL ownership |
| `ask-role-devops` | CI, containers, IaC, deploy |
| `ask-role-qa` | Substantial E2E/test harness |
| `ask-role-product` | Ambiguous / heavy product scope docs |
| `ask-role-design` | Design system / Storybook / tokens |
